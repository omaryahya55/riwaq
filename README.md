# رِواق

واجهة رئيسية وشاشة توقف **نظيفة وعربية** لتلفزيونات أندرويد (Android TV و Google TV).
بدل واجهة الشركة اللي فيها إعلانات مسلسلات وصور ما تليق: تطبيقاتك اللي تختارها بس، وشاشة توقف فيها الساعة والتاريخ الهجري وأوقات الصلاة والطقس والأسعار ومباريات فريقك.

مجاني، بدون إعلانات، بدون حساب، ومفتوح المصدر.

## وش فيه

**الواجهة الرئيسية**
- صف "تطبيقاتك": تختار التطبيقات اللي تطلع، وترتبها، وتخفي اللي ما تبيه (OK مطوّل)
- مداخل التلفزيون (HDMI) والإعدادات
- الصلاة القادمة والوقت والطقس

**شاشة التوقف**
- ساعة كبيرة، وتاريخ هجري (أم القرى) وميلادي
- أوقات الصلاة محسوبة على الجهاز (تشتغل بدون نت)، وتنبيه قبل الأذان
- الطقس الحين و ٥ أيام، وتنبيه الغبار
- الذهب والفضة والعملات وبيتكوين وإيثريوم
- جدول ترتيب الدوريات (روشن والدوريات الأوروبية الخمسة)، ومباراة فريقك
- العد لرمضان وعرفة وعاشوراء، والراتب وحساب المواطن (للسعودية)
- تذكير الجمعة والصيام، وشريط أخبار من مصدر تختاره
- تعتيم بالليل وحماية من حرق الشاشة

**الإعدادات من الجوال:** تصوّر باركود على التلفزيون، وتنفتح صفحة الإعدادات في جوالك. ما فيه كتابة بالريموت.

## التركيب

شوف [docs/SETUP.md](docs/SETUP.md). باختصار: تحمّل الأدوات على كمبيوتر، تشغّل "تصحيح USB" في التلفزيون، وتشغّل أمر واحد. والرجوع للواجهة الأصلية أمر واحد بعد.

> **ملاحظة صادقة:** رواق يبدّل الواجهة الرئيسية وشاشة التوقف. **اللي داخل التطبيقات نفسها** (إعلانات يوتيوب مثلاً) ما نتحكم فيه.

## الملفات

| المجلد | وش فيه |
|---|---|
| `web/` | الشاشة نفسها: صفحة ويب وحدة بدون مكتبات. تنفتح في أي متصفح للتجربة |
| `android/` | تطبيق أندرويد يغلّف الصفحة: الواجهة الرئيسية، وشاشة التوقف، وشاشة الباركود |
| `tools/` | سكربتات التركيب والرجوع (ADB) |
| `worker/` | سيرفر وسيط صغير (Cloudflare) للطقس والدوريات في النسخة العامة |
| `docs/` | التركيب، والخصوصية، والمحتوى الديني، وصور المتجر |

**تجربة الشاشة في المتصفح:**
```
python -m http.server 5310 --directory web
```
وبعدها افتح `http://localhost:5310` (الإعدادات: `http://localhost:5310/settings.html`).
